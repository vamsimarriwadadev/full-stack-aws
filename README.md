# About This Project: SkyAssist

SkyAssist is an enterprise Agentic AI assistant designed for airline operations and customer service workflows. Built with Python, FastAPI, LangChain, and Amazon Bedrock, it serves as an autonomous intelligent copilot capable of handling real-world operational and passenger interactions:

- **Flight Operations:** Look up real-time flight statuses, schedules, routes, gate assignments, and delay updates.
- **Booking Management:** Assist with passenger itinerary lookups, reservations, and travel modifications.
- **Enterprise IT & Operations Support:** Connect directly to internal IT Service Management (ITSM) systems to open tickets, triage incidents, and escalate operational issues.
- **Stateful Agentic Interactions:** Support multi-turn, context-aware conversations using dynamic tool calling, persistent session memory, and guardrails.

The project demonstrates a production-shaped, cloud-native agentic AI solution that bridges foundational language models with backend airline enterprise systems.
